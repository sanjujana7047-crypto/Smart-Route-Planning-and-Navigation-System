# Smart-Route-Planning-and-Navigation-System

A comprehensive C-based console application designed to demonstrate essential graph-based Data Structures and Algorithms (DSA) applied to real-world Indian highway logistics.

## 🚀 Features
This system implements seven fundamental graph algorithms to solve various routing and infrastructure optimization problems:

*   **Connectivity Analysis**: BFS (Breadth-First Search) and DFS (Depth-First Search) to verify network reachability.
*   **Point-to-Point Routing**: Dijkstra’s algorithm to find the shortest physical distance between two cities.
*   **Logistics Planning**: Bellman-Ford for calculating single-source distance vectors.
*   **Infrastructure Design**: Prim’s and Kruskal’s algorithms to compute Minimum Spanning Trees (MST) for cost-efficient highway connectivity.
*   **Global Lookup**: Floyd-Warshall to generate a cross-country distance matrix for all city pairs.

## 🛠️ Technology Stack
*   **Language**: C (Standard C99 compliant)
*   **Design**: Modular procedural programming
*   **Environment**: Compatible with GCC and standard online C compilers (e.g., Programiz)

## 📋 Algorithm Usage
| Algorithm | Best Used For |
| :--- | :--- |
| **BFS/DFS** | Mapping out transit paths and ensuring network integrity. |
| **Dijkstra** | Calculating the most fuel/mileage efficient route between two specific hubs. |
| **Bellman-Ford** | Assessing reachability in complex networks with potential cost variations. |
| **Prim/Kruskal** | Designing a backbone grid infrastructure with minimum cable/pavement cost. |
| **Floyd-Warshall** | Generating pre-cached distance tables for multi-stop navigation. |

## 🗺️ City Nodes (Data Set)
